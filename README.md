## Week 10: University Management System

The final project is a University Management System developed using JavaFX and MySQL.

The application connects to a MySQL database to retrieve and display student records.

### How to Run the Project

1. Open XAMPP and start MySQL.
2. Ensure the `university_db` database is available.
3. Open the `UniversitySystem` folder in Visual Studio Code.
4. Check the database connection settings.
5. Run the project using Maven:

   ```bash
   mvn javafx:run
   ```
